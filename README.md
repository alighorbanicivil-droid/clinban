# کلین‌بان — برنامه‌ریزی شیفت کلینیک

برنامه‌ی یک‌فایلی (PWA) برای مدیریت شیفت، کارکنان، گروه‌های شغلی، قوانین برنامه‌ریزی و گزارش‌های کلینیک. بدون سرور؛ داده‌ها در مرورگر (IndexedDB) ذخیره می‌شوند و پشتیبان رمزدار دارد.

## فایل‌های این بسته
- `index.html` — خود برنامه.
- `manifest.json` — مشخصات نصب (نام، آیکن‌ها، رنگ، حالت تمام‌صفحه).
- `sw.js` — service worker برای نصب‌پذیری و کار بدون اینترنت.
- `icon-192.png`، `icon-512.png`، `icon-maskable-512.png` و `apple-touch-icon.png` — آیکن‌های برنامه.
- `.nojekyll` — باعث می‌شود GitHub Pages فایل‌ها را بدون پردازش Jekyll منتشر کند.

**همه‌ی این فایل‌ها باید کنار هم و مستقیم در ریشه‌ی مخزن باشند، بدون پوشه‌ی اضافه.** اگر پوشه‌ی `icons` یا `manifest.webmanifest` نباشد، مرورگر پیام «نمی‌توان این برنامه را نصب کرد» می‌دهد.

## انتشار روی GitHub Pages
1. محتوای این پوشه (همه‌ی فایل‌ها و پوشه‌ی `icons`) را در ریشه‌ی یک مخزن بگذارید.
2. در تنظیمات مخزن: Settings → Pages → Source = `Deploy from a branch` و شاخه‌ی `main` با پوشه‌ی `/ (root)`.
3. بعد از چند دقیقه آدرس `https://...github.io/...` را باز کنید.

## نصب روی گوشی
- **اندروید (Chrome / Samsung Internet):** آدرس https را باز کنید، منوی مرورگر (⋮) را بزنید و «نصب برنامه» یا «افزودن به صفحه‌ی اصلی» را انتخاب کنید.
- **آیفون (Safari):** دکمه‌ی اشتراک‌گذاری را بزنید و «Add to Home Screen» را انتخاب کنید.

اگر باز هم پیام نصب خطا داد:
1. آدرس را حتماً در مرورگر اصلی (Chrome یا Safari) باز کنید، نه در مرورگر داخلی تلگرام یا اینستاگرام.
2. اگر قبلاً نسخه‌ی قدیمی را نصب کرده‌اید، میانبر قدیمی را پاک کنید.
3. در تنظیمات مرورگر، داده‌ی همین سایت را پاک کنید (Clear site data) و صفحه را دوباره باز کنید.

## نکات
- داده‌ها فقط در همین مرورگر ذخیره می‌شوند. برای انتقال، از بخش «پشتیبان» فایل رمزدار بگیرید.
- ماه‌های تأییدشده‌ی نهایی و روزهای گذشته‌ی دارای سابقه تغییر نمی‌کنند.
- برای کار بدون اینترنت، یک بار که آنلاین باز کنید کافی است؛ بعد از آن برنامه از حافظه‌ی مرورگر اجرا می‌شود.
