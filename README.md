# کلین‌بان — برنامه‌ریزی شیفت کلینیک

برنامه‌ی یک‌فایلی (PWA) برای مدیریت شیفت، کارکنان، گروه‌های شغلی، قوانین برنامه‌ریزی و گزارش‌های کلینیک. بدون سرور؛ داده‌ها در مرورگر (IndexedDB) ذخیره می‌شوند و پشتیبان رمزدار دارد.

## انتشار روی GitHub Pages
1. این پوشه را در یک مخزن (repository) بگذارید.
2. در تنظیمات مخزن: Settings → Pages → Source = `Deploy from a branch` و شاخه‌ی `main` با پوشه‌ی `/ (root)`.
3. آدرس نمایش داده‌شده را باز کنید.

فایل `.nojekyll` باعث می‌شود GitHub Pages فایل‌ها را بدون پردازش Jekyll منتشر کند.

## نکات
- داده‌ها فقط در همین مرورگر ذخیره می‌شوند. برای انتقال، از بخش «پشتیبان» فایل رمزدار بگیرید.
- ماه‌های تأییدشده‌ی نهایی و روزهای گذشته‌ی دارای سابقه تغییر نمی‌کنند.
- برای نصب روی گوشی، آدرس را در مرورگر باز کنید و گزینه‌ی «افزودن به صفحه‌ی اصلی» را بزنید.
